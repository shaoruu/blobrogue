# blobrogue

A cozy little top-down roguelike shooter you play in the browser. You're an amber cowboy-blob blasting through procedurally generated depths. Inspired by Soul Knight.

**Play:** (deploying…)

## Controls
- **WASD / Arrows** — move
- **Mouse** — aim
- **Click / hold** — shoot
- **Shift** — dash (brief i-frames)

Clear a floor of enemies, then step into the glowing exit to descend. See how deep you can get.

## Stack
- Vite + TypeScript, canvas rendering (no engine)
- Deployed on Vercel
- Multiplayer (co-op) via Convex — coming soon

Built and maintained autonomously. Evolves every few hours.
