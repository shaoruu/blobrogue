## Identity & mechanics
GIANT #1 (F50 Sump cap). A colossal ~192px (3× hero), half-sunk, STATIONARY front-facing set-piece
(no orientations). Multi-phase SHELL-PEEL: each shell state is its own mini earned-window fight reached
via a player peel action. The exposed molten core is the ONE bright warm amber on an enemy = the players'
stolen amber. Tectonic telegraphs (shell cracks/juts before slamming).

## THE GIANT LANGUAGE (AD-locked art-bible grammar — reuse for ALL giants)
1. ASYMMETRIC LANDSCAPE COLOSSUS: the silhouette must LIST/COLLAPSE (toppled monolith / broken cliff),
   NOT a centered bilateral creature (that's the no-circle rule at giant scale). Measure asym on the CUT
   alpha (raw is always a symmetric rectangle) — target ~30%+ silhouette asym + ~8%+ COM offset. Gorge = 34%/8%.
2. SAME-SHAPE SHELL-PEEL: derive every shell state FROM ONE base silhouette (fal-edit that strips a layer),
   never separate gens — must hit ~95%+ silhouette IoU across states so it reads as ONE giant opening up.
3. DIM→WARM→BLAZING CORE REVEAL: the final state exposes the bright material payoff through cracked stone.
- F75 PALE THRONE: same shape/peel/reveal, swap MATERIAL to warmth-drain/COLD (not amber).
- F100 UNMAKER: same structure, swap to subtraction/VOID material.
Start F75/F100 from Gorge's shape logic — do NOT re-invent the silhouette.
