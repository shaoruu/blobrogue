# blobrogue — CONTENT EXPANSION ROADMAP → FLOOR 100
**Creative Director recommendation to the main project runner. NON-CANONICAL. Recommendations only; runner integrates + builds. Fits shipped systems: protocol v15, earned-window bosses, party/gear scaling, deterministic authoritative sim, no-circle art rule, scene attention hierarchy.**

## The frame for post-F30
Floors 1–30 are the known descent (Amberwild→Emberreach). Post-F30 is **THE UNMAKING**: the corruption you descended toward now spreads back through the world's substrate. This is the home of Null + Jet already reserved in canon. Four post-30 regions reuse the existing hazard/ecology/telegraph FOUNDATION with new corrupted material, not new engines:
- **F31–50 THE SUMP** — everything drains together; warm/cold materials melt; corrupted mixed ecology.
- **F51–70 THE VEINWORKS** — the corruption's circulatory system; resin/amber arteries; Fracture made environmental.
- **F71–90 THE PALE** — warmth/color draining out; subtraction begins; approaching Null.
- **F91–100 NULL CORE** — subtraction complete; the source; the ending + Amber Heart restoration.

## Two hard PREREQUISITES before deep content ships (from the bestiary/arsenal audits)
1. **Biome-selective roster/encounter deck.** `floorRoster()` is currently cumulative/global; without biome exclusions, deep floors will still feel same-y no matter how much we add. Fix first.
2. **Four-player effect-density / telegraph-priority controller.** No unified per-player/boss/hazard reservation exists. Giants + mutators + 4 players WILL become unreadable soup without it. This is a gate, not polish.
Adding volume before these two makes the repetition WORSE, not better. Flag to Ian: these unlock everything after.

# 2. MORE GUNS — new VERBS, batched
Beyond Camp Iron (neutral) + Hollow + High Noon. Each is a new room verb, not a stat clone. Coordinate mechanics with game designer.

New verbs:
- **DEPLOY** — Amberwork construction: place a temporary turret/cover node you fight around (reframes old Goldwork as material construction, not runes).
- **MODESHIFT** — one weapon, two committed modes you swap (close burst ↔ far lance); the decision is when to shift.
- **GAMBLE** (the "mystery" tier) — shot type rerolls each reload from a seeded authored pool; embraces Ian's "randomness" while staying deterministic.
- **TETHER** — link to an enemy: reposition it or yank yourself; a movement/control gun.
- **SET & DETONATE** — place charges, detonate on your timing; spatial premeditation.
- **RETURN/PARRY** — absorb an incoming projectile volley and fire it back; reactive defense as offense.
- **ROOT & RAMP** — powers up the longer you hold ground/stand still; the anti-kiting verb (pairs with High Noon's Duel and Hollow low-HP).
- **COMMAND** — spawn temporary splinter-allies you point at targets (bounded, no pet economy).

Legendary tier (build-around uniques, each bends ONE rule; GD-gated): e.g. a weapon that auto-fires your Resonance at low frequency; a melee that returns projectiles; a slug that seeds Fracture on every wall. One rule bent each, never raw stat kings.

Batches:
- **Wave 1 guns:** DEPLOY (Amberwork), MODESHIFT, GAMBLE (mystery) — plus finish the already-queued Hollow pair (Ruinbreath+Widowbite) + Black Lantern.
- **Wave 2 guns:** TETHER, SET & DETONATE, RETURN/PARRY.
- **Wave 3 guns:** ROOT & RAMP, COMMAND, + first legendaries + mystery-tier expansion.
Reject list stands: no straight-bullet/SMG/short-cone/rail/colored-status clones; new guns must change position, target priority, room geometry, or timing.

# 3. MORE ENEMIES + CRAZINESS/RANDOMNESS
## Deep enemies
Extend the biome ecology into corrupted apex variants (Sump/Veinworks/Pale/Null) using existing verbs (HUNT/ORBIT/BURROW/ANCHOR/FLOCK/FLEE-BAIT) + one genuinely new deep verb per region max. No stat reskins; each must pose a new room decision and be silhouette-readable.

## Randomness systems (ALL seed-driven → deterministic + authoritative-safe)
The replay engine. Every roll happens once, server-authoritative, at generation time, baked into the snapshot — never per-client RNG.
1. **FLOOR MUTATORS ("Warps"):** each deep floor rolls 0–2 from an authored pool: Dense Dark (vision limited), Molten Floor (moving safe tiles), Twinned Elites, Fracture Storm (periodic global snap), Amberfall (destructible cover rains in), Thin Air (longer dashes). Pure-data toggles the sim already expresses (vision/hazard density/spawn count/tile behavior) → low engine risk. This is the primary "craziness" dial.
2. **ELITE AFFIXES:** one seeded affix max per elite, silhouette/material-readable: Splits-on-death, Shielded-until-ally-dies, Hazard-trail, Reflect-one-shot, Enrage-low-HP. One only, always readable.
3. **RANDOM EVENTS/ROOMS:** authored special rooms seeded in — gamble shrine (risk/reward), cursed treasure (power + a mutator), wager arena, "the floor hunts you" chase.
4. **DEEP BOSS AFFIXES:** past F30, a boss floor can roll ONE extra telegraphed boss pattern so familiar bosses fight fresh — directly fixes the repeated-boss feeling.
5. **SEEDED/WEEKLY RUNS:** shared seed for competitive parity (ties to the normalized-boards rec).

Determinism guardrails: rolls seeded from run seed + floor index, resolved authoritatively, part of snapshot; mutators expressed only through data the sim already simulates; caps: max 2 floor mutators, 1 elite affix, 1 boss affix, and mutators respect the 4P density controller so "crazy" never becomes "unreadable."

## GIANT calibration — HARD RULE (GD-locked)
Giants are calibrated PER-PHASE on exposed-time, never one inflated bar. A giant = K sequential phases, each a fraction of a standard boss's exposed HP; total TTK ~1.4-1.6× a standard boss via PHASE COUNT, never 4× HP. Each shell layer is its own mini earned-window fight reached via a player peel action; TTK gates override HP per-phase; co-op scales the TASK (more shell segments/peel points), not the bar. Giants are unshippable without prerequisite 2.

## Wave 1 boss reshapes (GD-locked)
- JET: mirror pool AUTHORED per Resonance family + seeded (mirrors archetype, not literal inventory); simultaneous mirrored-verbs capped to the telegraph budget.
- THE TITHE: re-armor beatable at ~60-70% median-party slab-TTK; missing the window costs but loops (never dead-ends); co-op = more/thicker slabs, not a shorter timer; always leave one line-of-sight lane.
- QUORUM: husk ROLES (shield / heal-the-pool / damage) make kill-order real and stop even-nuke skips; telegraphed 1.2s non-invuln merge; merged fast-form gets its own window with widened ≥.45s recover.
